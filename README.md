# Sistema de Cadastro de Usuários

Projeto de cadastro de usuários desenvolvido com HTML, CSS e JavaScript, com funcionalidades completas de CRUD (Create, Read, Update, Delete).

## 🚀 Funcionalidades

- Cadastro de usuários
- Edição de informações
- Exclusão de registros
- Listagem de usuários
- Busca por nome ou e-mail
- Validação de dados
- Persistência de dados com localStorage

## 💻 Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## 🌐 Acesse o projeto

https://vpmmarquess.github.io/sistema-cadastro

## 📌 Objetivo do projeto

Este projeto foi desenvolvido com o objetivo de praticar lógica de programação, manipulação do DOM e desenvolvimento de aplicações web simples.
